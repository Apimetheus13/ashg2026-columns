# 基因體頭條專欄（2026 年 10 月）

這個網站收錄 23 篇個人分享的專欄，版面改為每日早報。最新一批的頭條與更新專欄，集中在頁面最上方、標有日期的早報區，並以標題連結清單列出；其後依序是 GenomeWeb Daily News 與 ASHG 2026 兩個區塊。

已新增手機導覽：右下角有浮動的「目錄」按鈕，每篇專欄文末有「↑ 回目錄」連結，兩者都會回到早報的標題清單。

更新於 2026-10-30。
