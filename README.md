已新增手機導覽：右下角有「目錄」與「搜尋」。搜尋列在頁面上方，捲動後會吸在頂端，可搜專欄標題、原始英文標題與內文，不分大小寫。標籤與日期清單寫在 `data/columns.js`。篩選狀態用網址查詢參數 `?q=` 與 `?tag=`，不用井字號，因為井字號已經用來跳到 `#c122` 這類專欄錨點。

新增一天早報時：

1. 在 `index.html` 最上方的早報區改成新的一天，新專欄仍用下一個編號、`section id="cNNN"`、`<h2>` 與 `<p class="orig">`。
2. 打開 `data/columns.js`，把新的一天插到 `days` 陣列最前面。陣列第 1 天要和頁面上展開的早報同一天；第 2、3 天會出現在「近三天」，其餘自動進「更早的早報」。
3. 在同一個檔案的 `tags` 為每個新專欄 id 寫 2–4 個標籤，只能用檔案開頭 `vocabulary` 裡的詞。搜尋索引會從專欄本文自動建立，不必把內文再抄一份。
